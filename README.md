# FreeCodeCamp - Responsive Web Design

This repository contains my learning progress and practice exercises from the Responsive Web Design course on freeCodeCamp.

## About This Repository

I created this repository to document my journey in learning web development, improve my HTML skills, and practice building web page structures.

## Projects and Exercises

The exercises in this repository include:

- **Iframe** – Practicing how to embed external content using HTML iframe.
- **SVG Heart Red** – Learning to display SVG graphics in HTML.
- **List of Major** – Practicing HTML list elements.
- **Quincy Job** – HTML practice exercise.
- **Video Complicated** – Practicing video embedding in HTML.
